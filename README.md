# Hangman Game (Python)

A simple command-line Hangman game built with Python. The player must guess a hidden word one letter at a time before running out of attempts.

---

## 🎮 How to Play

- A random word is selected at the start of the game
- You guess one letter at a time
- Each wrong guess reduces your remaining attempts
- You win by guessing the full word before running out of lives

---

## 🧠 Features

- Random word selection
- Input validation (prevents repeated/invalid guesses)
- Tracks correct and incorrect guesses
- Win/lose game conditions
- Simple ASCII hangman stages (optional if you added them)

---

## 🛠️ Built With

- Python 3
